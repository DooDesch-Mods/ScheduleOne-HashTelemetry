hash # shared requests

hash turns a line like # give me five OG Kush into a console command, offline, with a 45 MB model that ships with the mod. That model was trained on requests another model was asked to invent. This page counts the real ones, sent by players who switched sharing on.

No names, no saves, no timestamps beyond the day. The command words below are the game's own; what a player typed stays in the file and is never shown here.
